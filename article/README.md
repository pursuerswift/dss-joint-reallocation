# Reproduce the article displays

The manuscript studies joint selection and transfer matching under a fixed service capacity. The three archives listed in the [repository README](../README.md) contain the original code, experiment configurations, paired simulation records, scalar budget frontiers and aggregate cohort results. Read [DATA_SOURCES.md](../DATA_SOURCES.md) for access to original cohort records.

From a clone of this repository, run `python article/extract_results.py` with Python 3. The script reads the deposited archives directly, regenerates `figure_3.csv` (conditional gross benefit, transfer cost and net value per 1,000 records) and `historical_candidates.csv` (nine prespecified candidates). It also checks the 324 retention decisions under each of three rules. To reproduce the standalone vector artwork for Figure 3, run `xelatex figure_3.tex` inside `article/`. It reads the plotted values from the CSV.

For all other displays, extract the three archives in the order given in the repository README and follow [the reproduction guide](../REPRODUCE_20261119.md). Experiment paths below are relative to `experiments/upgrade_v3/results/` in the extracted release.

| Display | Archived source |
|---|---|
| Figures 1 and 4 | `papers/dss/v3_joint_reallocation/revision_figures.py` in the extracted release. Figure 4 uses `revision_v3_20261117/conflict/`. |
| Figure 2 | Constructed two-pair example in `papers/dss/v3_joint_reallocation/publication_figures.py`. |
| Figure 3 and Table 1 | Strong costs in `major_revision_20261118/revision/summary.csv` (headline compatibility, full cap). Moderate costs in `submission_final_20261119/final_focus/summary.csv` (6,000 records, strength 0.5, full cap). |
| Table 2 | `joint_v3_20261117/mechanisms/summary.csv` and `paired_contrasts.csv`, strength 1 and score-noise SD 0.04. |
| Table 3 | `revision_v3_20261117/conflict/`, both cost families at full strength and full cap with known benefits. |
| Figure 5 and Table 4 | `major_revision_20261118/revision/contrasts.csv` for the 20-draw grid and `submission_final_20261119/final_focus/contrasts.csv` for its 100-draw extensions. The first 20 draws are shared. The heatmap is generated by `experiments/upgrade_v3/revision_outputs.py`. |
| Table 5 | `joint_v3_20261117/benchmark/runtime.csv`, three executions per fixed instance. The separate prefix-stopping timings are in `submission_final_20261119/final_timing/`. |
| Tables 6 and 7 | `expanded_v3/empirical/` contains partition designs, candidate test estimates, simultaneous adoption bounds and frozen decisions. `historical_candidates.csv` gives unrounded values for Table 7. |
| Penalty path | `expanded_v3/penalty_path/candidate_values.csv` and `decision_values.csv`. |
